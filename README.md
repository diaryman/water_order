## Deployment Guide 🚀
For detailed installation instructions (Ubuntu/Docker/Windows), please check [DEPLOYMENT.md](./DEPLOYMENT.md).

## Getting Started
First, install dependencies:
```bash
npm install
npx prisma generate
npx prisma db push
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
